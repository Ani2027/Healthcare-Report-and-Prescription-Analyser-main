# Medical AI Frontend Application

This directory contains the React 19 + Vite frontend application for the **Healthcare Report & Prescription Analyzer**.

## Features
- **Modern UI / UX**: Built with Tailwind CSS, Lucide React icons, and Framer Motion animations.
- **Multimodal Report Analyzer**: UI interface to upload PDFs and images for automated medical report extraction.
- **Prescription Reader**: Image uploader for analyzing handwritten prescription notes.
- **Doctor Assistant Chat**: Interactive AI symptom triage chat with history and memory support.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
